# Models

Validation sheets for the telecom churn models. Reproducible training via `scripts/train_models.py` (fixed seed, `random_state=42`).

Training environment: Python 3.14, scikit-learn 1.9.0, XGBoost 3.3.0, pandas 3.0.3. **These versions are pinned in the services' Docker images** — a joblib artifact is only guaranteed to reload with the same version of the library that produced it.

## Model 1 — Churn score (`churn_model.pkl`)

- Dataset: Telco Customer Churn (IBM), 7,043 rows, 80/20 split stratified on the target
- Type: binary XGBoost (`XGBClassifier`, 300 trees, depth 5), `predict_proba` → score between 0 and 1
- Main metric: **AUC = 0.838** (accuracy 0.801, F1 0.588 at the 0.5 threshold — dataset imbalanced at 26.5% churn, hence AUC as the reference metric)
- Artifact size: 209 KB
- Average inference time (local, Apple Silicon): **0.14 ms/row**

## Model 2 — Offer recommendation (`offer_model.pkl`)

- Dataset: 5,000 synthetic rows derived from the Telco dataset (labels generated by fictional business rules + 10% noise, 5 offer categories), 80/20 split
- Type: multiclass RandomForest (100 trees, depth 8, `min_samples_leaf=5`)
- Main metric: **accuracy = 0.928** (macro-F1 0.792; the theoretical ceiling is ~0.90 excluding noise — the model also learns part of the noise)
- Artifact size: 712 KB
- Average inference time (local): **13.2 ms/row** (`predict_proba`; `predict` alone, used in production, is faster)

## Model 3 — K-Means segmentation (`kmeans_model.pkl`, optional, CronJob)

- Dataset: full Telco Customer Churn, transformed features (same preprocessor as the other two models)
- Type: K-Means, k=4
- Metric: silhouette = 0.231; cluster sizes: 1976 / 2621 / 1526 / 920
- Artifact size: 5 KB
- Usage: scheduled recomputation of the segmentation as a Kubernetes CronJob (off the synchronous path)

## Shared preprocessing (`preprocessor.pkl`)

- `ColumnTransformer`: `StandardScaler` on 4 numeric columns + `OneHotEncoder(handle_unknown="ignore")` on 15 categorical columns → dense vector of **45 features**
- Fit on the train split only (no data leakage)
- Size: 2 KB
- Loaded by the **preprocessing** service in production; column definitions and type coercion live in `services/preprocessing/app/features.py`, a module imported by both training and the service (single source of truth)
